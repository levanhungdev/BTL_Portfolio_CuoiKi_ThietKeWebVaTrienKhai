01. Giới thiệu

Mình học Phát triển phần mềm tại FPT Aptech (2024 – 2026) và hiện đang tiếp tục học đại học tại Đại học Đại Nam. Mình có nền tảng về thiết kế hệ thống và phát triển web với Java (Spring Boot), .NET, Node.js và ReactJS.

Trong kỳ thực tập R&D tại VNATECH, mình là sole developer xây dựng sản phẩm phần mềm nội bộ đầu tiên của công ty: một hệ thống quản lý kho gồm backend, web admin và ứng dụng tablet, hoàn thành trong hơn 1 tháng.

Mình thích học công nghệ mới, làm việc nhóm tốt và luôn hướng tới những sản phẩm chạy được thật sự.

Sở thích: Lập trình · Đá bóng · Nghe nhạc

Mục tiêu ngắn hạn 3–6 tháng

Vận dụng kiến thức vào công việc thực tế, nhanh chóng thích nghi với môi trường doanh nghiệp và hoàn thành tốt giai đoạn thử việc.

Mục tiêu dài hạn 1–2 năm

Trở thành Fullstack Developer chuyên nghiệp, thành thạo cả Frontend và Backend, hướng tới vị trí Senior Developer hoặc Team Leader và BRSE.

04. Dự án

Nổi bật

Warehouse Management System

Hệ thống quản lý kho nội bộ greenfield cho VNATECH: sole developer, hoàn thành trong 1 tháng.

  • Backend Go/Gin/GORM với 10 domain models (User, Product, Location, Inventory, Import, Export, Transaction...), RESTful API và middleware CORS.
  • PostgreSQL schema 10 bảng, dùng GORM auto-migration.
  • Web admin React 19 gồm 11 trang (Dashboard Chart.js, Inventory, Orders, Report, UserManagement...) với Vite và Axios.
  • Tablet app Flutter cho nhân viên kho: quét QR/Barcode bằng mobile_scanner, quản lý state bằng Provider.
  • Embed bản build React vào file thực thi Go, phục vụ SPA và API chung một port, triển khai LAN đơn giản.
  • Quy trình khép kín: quét QR → tạo/quản lý phiếu nhập xuất → tự cập nhật tồn kho và lưu giao dịch.
  • Go
